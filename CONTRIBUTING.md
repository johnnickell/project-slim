# Contributing

Use a feature branch from `develop`, keep approved TASK slices independently verifiable, and run `./bin/build`
before committing or requesting review. Follow the [engineering standards](docs/engineering/STANDARDS.md) and
[shared Pi workflow binding](docs/engineering/WORKFLOWS.md). The installed provider supplies skills; this project
supplies its requirements, paths, gates and completion policy. Do not copy Fight package source or provider planning.

Work hands committed evidence to independent Spec/Standards review, then applicable behavioral QA and separately
authorized land. Missing/stale acceptance or required hosted evidence holds the affected delivery stage. Neither
implementation completion nor a merged bootstrap implies release, deployment or permission to publish.
