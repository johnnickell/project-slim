# Fight Slim Starter

Public Slim application composition for Fight libraries. Run `./bin/build`, then start the bootstrap with
`./bin/up`; it prints the exact loopback URL. Open that URL to receive `Fight Slim starter is ready.` The build
is the canonical verification gate.

This is a foundation only. Login, persistence, browser journeys, releases, tags, Packagist publication, template enablement, and create-project distribution are intentionally excluded.
