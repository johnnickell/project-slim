# Local issue tracking

Repository-local EPIC/TICKET/TASK metadata owns scope, status, priority, and dependencies. Requirements are not
executable work; the Board routes to TASKs only. Keep its manually maintained views truthful while generation is
pending. Mark completion only with verified acceptance and a green required gate. Old PRD/T-ticket IDs survive only
as historical prose in migrated records and `planning/MIGRATION.md`, never as parser aliases or a second status system.
