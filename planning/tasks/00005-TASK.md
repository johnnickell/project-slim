# Retire Framework Certification

## Outcome and Scope

Remove the deliberately retired framework-support certification obligation while keeping a coherent application
verification path on the existing main lock. Covers [TICKET-00009](../tickets/00009-TICKET.md) AC-01 through AC-05.

In scope: lowest/latest lane execution, lowest lock/digest, no-dev checks, certification-only upstream cloning,
receipt artifacts/generation/verification, their callers and obsolete tests, and operative support documentation.
Classify test removals by purpose and retain meaningful application and package-integration behavior.

Out of scope: substitute certification, dependency-version updates, full runtime/gate modernization, product
behavior changes, deleting useful tests just because they touch dependencies, and archiving historical records.
No business messages, permissions, or product state transition applies.

## Acceptance Criteria

- [ ] **AC-01:** The main `composer.lock` remains authoritative and unchanged; the lowest lock/digest and lane execution
  are retired without adding a substitute matrix or no-dev requirement.
- [ ] **AC-02:** No active gate path generates/verifies framework receipts, clones package source solely for that
  certification, or installs a separate no-dev graph. Deleted files have no live executable callers.
- [ ] **AC-03:** Certification-only tests are removed with an explicit disposition; meaningful booted behavior and
  security/configuration rejection evidence is retained for later suite alignment. No product tests of the retired
  machinery are recreated elsewhere.
- [ ] **AC-04:** Operative docs describe the narrowed single-lock support claim. Historical TASK-00012/TASK-00014 outcomes (former T-00002/T-00005) remain
  historical evidence; removed artifact paths are not presented as available verification commands or fresh receipts.
- [ ] **AC-05:** Ordinary setup, retained application/integration tests, and the remaining canonical build work without
  changing dependency versions or intended public behavior. Local results and actual hosted results are distinguished.
